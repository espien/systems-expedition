# Systems Expedition

Miscellanious resources, and excercises for (re)-re-learning C.

# [Beej's Guide to C Programming](beejs-guide/)

Notes and some code examples taken from [Beej's Guide to C Programming](https://beej.us/guide/bgc/html/split/). Chapters are separated by directories, each containing a NOTES.md file.

# [Small programs](small-programs/)

Contains simple and small *hand-written* programs that do not deserve their own repository. Separate programs folders contain their source code and a NOTES.md file. The NOTES.md files are a sort of retrospective done afterwards.
